Find exact duplicate photos, safely

One command prints which photos in a folder are byte-for-byte copies, which one it would keep, and how much space the extras use. It is a dry run: it never deletes or moves anything.

python3 tidy_dupes.py ~/Pictures

Download tidy_dupes.py (about 100 lines, plain Python 3, no extra packages).

What you need

The free, open-source czkawka_cli on your PATH. Check the file's sha256 on the release page before you run it.

What it does and does not do

  • Exact copies only (same bytes), including small files; empty files are ignored. It does not find "similar" photos.
  • Tested on JPEG and BMP in a small synthetic folder. PNG and WebP are not verified.
  • Keeps the oldest-modified file in each group and lists the rest as copies.
  • This is an early experiment, not a finished product. Czkawka and its authors are not involved.
